OAuth GuideHub for AI Agent Builders

Architecture decisions, real-world evidence verification, agent delegation strategy, and product trade-offs.

1 Understanding the Developer & AI Agent Friction

When developers build AI agents that require connecting to end-user SaaS tools (Gmail, Slack, HubSpot, Salesforce), they face a critical roadblock: The Provider OAuth Gap.

  • Uncertain Timelines: Is this a 10-minute API key setup, or a 6-week CASA security audit requiring a $2,000 third-party review?
  • Scope Misconfiguration: Requesting one wrong restricted scope forces an entire re-review and app reset.
  • Human vs. Agent Task Confusion: Developers need clarity on what an automated agent script can handle (generating privacy policy drafts, configuring redirect URIs) versus what requires human executive action (D-U-N-S verification, video demo recording).

2 Evidence Testing, Corrections & Discrepancies

Verified & Corrected Insights
  • • Google Workspace: Unverified app screen allows local testing for up to 100 internal users immediately without review delay.
  • • Slack Granular Scopes: Bot token scopes (e.g., chat:write) do not require workspace re-approval if installed in personal workspace.
  • • Salesforce: Requires enabling "Enable OAuth Settings" in Connected Apps which takes 2–10 minutes to propagate across global edge networks.
Remaining Uncertainties & Unverified
  • • HubSpot App Marketplace vs. Private Apps: Private apps bypass review entirely for single-tenant agents, whereas public OAuth requires partner portal signoff.
  • • Dynamic CASA Security Audits: Third-party security assessment pricing ($1.5k–$5k) varies depending on cloud infrastructure complexity.

4 6–8 Hour Budget Trade-offs & Scope

What was prioritized: Deep, actionable quality on 5 diverse OAuth archetypes (Google = high compliance review, Slack = instant bot scope, Salesforce/Hubspot = enterprise domain approval, Spotify/Linear = fast standard OAuth), plus a realistic live agent investigation simulator capable of parsing any custom input.

What was deferred for production: Direct live scraping of behind-login developer portals (requires headless browser pool & paid credentials), automated OAuth callback URL verification testing ping.
